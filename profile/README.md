## ✨ Features

- 🎨 **Modern Dark UI** - Kick.com inspired design with green accents
- 🌍 **Multi-language** - English & Persian (فارسی) with RTL support
- 🔒 **Privacy First** - No tracking, no analytics
- ⚡ **Lightning Fast** - Instant DNS switching
- 📡 **40+ DNS Servers** - Including Vanilla DNS, Cloudflare, Google, and Iranian services

## 📥 Quick Install

### Desktop App

Download from [**Releases**](https://github.com/Vanilla-DNSChanger/vanilla-dns-changer/releases/latest)

### CLI

```bash
npm install -g @vanilla-dns/cli
vdns connect -n vanilla
```
